   либо воспроизведено у нас в `out/runs.jsonl`.
2. [S][?] разрешено только для *порядка* приоритетов (что пробовать первым), не для обещаний.
3. Прогноз «мы получим X×» обязан иметь строку в `05-RESULTS.md` с планом измерения
   до того, как будет написан любой код под этот выигрыш.
