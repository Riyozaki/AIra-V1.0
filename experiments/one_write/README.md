# one_write — ставка «память решается, а не обучается»

Смысл и числа: `docs/07-ONE-WRITE.md`.

    python3 test_rls.py       # паритет поток==пакет, 1 проход==решатель, FD замкнутого grad
    python3 probe_learn.py    # эпохи против 0 эпох на unseen-отображениях
    python3 probe_fair.py     # float32-дрейф + честная метрика для SGD-рук

- `lc_rls.py` — RLS-поток (`rls_write_seq`, `rls_stream`), батч-решатель (`rls_solve_batch`),
  и **замкнутый градиент через решатель** (`rls_grad_batch`) — обучение адресации без
  обратного прохода по T. Формула: `S = A⁻¹ dL/dW`, `dV = K S`, `dK = (V − KW) Sᵀ − K(S Wᵀ)`.
- Ничего не «ускорено в обход спецификации»: поток сходится с пакетом до 0.0e+00,
  проход сходится с решателем до 1e-15, FD подтверждает градиент до 4e-09.
